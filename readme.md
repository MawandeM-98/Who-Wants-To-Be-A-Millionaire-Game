# 💰 Who Wants to Be a Millionaire

A fully functional, interactive quiz game inspired by the iconic TV show. Built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## 🚀 **Installation**

### **1. Clone the Repository**

```bash
git clone https://github.com/MawandeM-98/Who-Wants-To-Be-A-Millionaire-Game.git
cd Who-Wants-To-Be-A-Millionaire-Game
2. Run Locally
Simply open index.html in your browser:

bash
# Double-click index.html in File Explorer
# OR use Live Server in VS Code
3. No Dependencies
This project has zero external dependencies — just open and play!
